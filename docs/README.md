# 프로젝트 지식

이 디렉터리는 이 프로젝트를 작업하는 데 필요한 프로젝트별 지식과 지침을 관리합니다.

## 문서 목록

- [구현 계획](implementation-plan.md)
  - macOS용 Rich Markdown Diff 앱의 확정 요구사항, 제안 설계, 구현 순서와 수용 기준을 확인할 때 참고합니다.

- [빌드·실행 및 기능 안내](../README.md)
  - 앱 실행, `rmdiff` 설치, 코멘트와 파일 트리 사용법, 개발·테스트 명령을 확인할 때 참고합니다.
- [구현 및 검증 결과](../VERIFICATION.md)
  - 실제 수행한 검증과 미검증 범위, 알려진 제한, 증거 파일을 확인할 때 참고합니다.

- [GitHub Release 자동 배포](release.md)
  - `release` 브랜치 배포, 태그 규칙, 다운로드 파일과 재실행 방법을 확인할 때 참고합니다.

## 현재 구성

현재 프로젝트 루트의 `native/`, `web/`, `tests/`, `scripts/`에서 앱을 구현합니다.
구현 계획의 별도 프로젝트 생성 지시는 현재 프로젝트로 통합해 달라는 후속 요청으로 대체됐습니다.
`AGENTS.md`와 기존 스킬 연결 구조는 유지합니다.
후속 기능으로 특정 커밋과 현재 작업 디렉터리의 비교를 지원합니다. 사용 범위와 선택 방법은 루트 README를 참고합니다.
